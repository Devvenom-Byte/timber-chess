TIMBER CHESS - how to put it online (free, about 5 minutes)

OPTION A - GitHub Pages (permanent, free)
1. Go to github.com, sign in, click "New repository". Name it timber-chess, set it to Public, click Create.
2. Click "uploading an existing file" and drag in ALL the files from this folder
   (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, apple-touch-icon.png). Click "Commit changes".
3. Go to Settings > Pages. Under "Branch" choose "main" and "/ (root)", then Save.
4. After a minute your app is live at:  https://YOUR-USERNAME.github.io/timber-chess/

OPTION B - Netlify Drop (fastest)
1. Go to app.netlify.com/drop
2. Drag this whole folder onto the page. You get a link straight away.
3. Create a free account when it asks, so the site stays up (unclaimed drops are removed).

USING IT
- Send the link to anyone. It opens in their phone's browser, no download or sign-up.
- To make it a real app icon: on iPhone open the link in Safari, tap Share > "Add to Home Screen".
  On Android, Chrome shows "Install app" (or Menu > Add to Home screen).
- To play a friend: Family tab > Invite a friend > New game > Send link.
  They can join any time: games are saved online, so you can play live together or take turns whenever you like.
- Computer, openings and puzzles work offline once the app has been opened once.

UPDATING
Replace index.html with a new version (same upload steps). Phones pick it up next time they open it.
